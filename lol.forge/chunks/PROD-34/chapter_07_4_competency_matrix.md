## 4. Competency Matrix

### 4.1 Competency Categories (Per Role)

Each role requires competency across five categories (Knowledge, Skill, Behavior, Judgment, Digital):

| Category | Description | Assessment Method |
|----------|-------------|-------------------|
| **Knowledge (K)** | Theoretical understanding of physics, systems, procedures | Written exam (80% pass) |
| **Skill (S)** | Hands-on execution of tasks, tool use, equipment operation | Practical assessment (instructor sign-off) |
| **Behavior (B)** | Safety culture, communication, procedure adherence | Behavioral observation checklist |
| **Judgment (J)** | Decision-making at authorization gates, anomaly response | Scenario-based oral board |
| **Digital (D)** | Digital twin interaction, data interpretation, cyber hygiene | Simulator + cyber range assessment |
