## 13. Refresher & Recertification

### 13.1 Recertification Schedule

| Frequency | Activity | Duration | Trigger |
|-----------|----------|----------|---------|
| **Annual** | Refresher modules (F-01, S-03, O-04, M-01) | 40 hrs | Calendar |
| **Biennial** | Full recertification (written + practical + sim) | 80 hrs | Cert expiration |
| **Post-Incident** | Targeted remediation (specific scenario) | 8-16 hrs | NCR/incident report |
| **Post-ECO** | Delta training (design change impact) | 4-8 hrs | ECO implementation |
| **New Firmware** | L0/L1/L2/L3 version upgrade training | 8 hrs | Git tag release |

### 13.2 Remediation Protocol

1. **Assessment Failure**: Immediate supervised operation only → 2-week remediation → re-assess
2. **Simulator Failure**: Scenario-specific coaching → 3 practice runs → re-assess
3. **Judgment Failure (Oral Board)**: Root cause analysis → mentored gates (5×) → re-board
4. **Behavioral Deficiency**: Safety stand-down → culture coaching → 30-day observation
