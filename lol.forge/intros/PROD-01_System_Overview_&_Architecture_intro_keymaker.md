# Keymaker Heuristic — Lock, Key, Turn
## Document: PROD-01 — System Overview & Architecture

---

### The Empirical Lock

The lock this document addresses is the **fabrication fidelity gap** — the persistent failure of metallurgical engineering to simultaneously achieve: complete elemental recovery from mixed feedstock, Carrington-event immunity (zero conductive paths), zero-waste gas capture, and domestic critical mineral production (In, REE, Zr). For decades, each has been a separate facility: smelters for metals, refineries for REE, ceramic kilns for oxides. The lock is precise: any single machine claiming to unify elemental extraction must produce pure element slugs from arbitrary input with zero metal infrastructure — and must explain why induction heating + centrifugal separation achieves what chemical processing cannot.

---

### The Mathematical Key

The key is the **thermophysical cascade as single computational primitive**. The teeth are cut by the periodic table itself:

| Element Class | Thermal Stage | Separation Mechanism | Output |
|---|---|---|---|
| Organics/Water | 80-450°C | Vaporization + condensation | Water, char |
| Low-temp metals | 420-900°C | Inductive melt + centrifuge | Pb, Sn, Zn, In slugs |
| Aluminum | 660-720°C | Selective Al window | Al alloy slugs |
| Copper/Precious | 1085-1200°C | Deep-penetration induction | Cu + Au/Ag/Pd slugs |
| Ferrous/REE | 1200-1600°C | Ferromagnetic induction | Fe + Nd/Sm/Co slugs |
| Refractory minerals | 1600-2200°C | Zircon dissociation | ZrO₂ + REE oxide concentrate |

The cascade temperature profile is unique, deterministic, and parameter-free. The feedstock enters only as the boundary condition that the profile must process.

### The Turn (Both Directions)

**Key → Lock (Theory predicts recovery):** Input: Feedstock assay → Phase diagram → Thermal cascade profile. Output: 8 pure slug streams, gas capture, mineral concentrate. Validation: Recover >95% of each element class; match historical smelter yields without chemicals.

Output: Verified that each industrial process is a *subset* of the cascade — the cascade contains them all simultaneously. The turn completes when the forge produces In, Nd, Zr from e-waste in a single batch. That moment — when 50 elements report to 8 ports — is the lock clicking open. The slug *is* the key turning in the lock.
