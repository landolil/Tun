## 3.6 Cross-Sub-Group Coordination — Wallmapu Wenuy Protocol

### 3.6.1 Inter-Sub-Group Consent for Transboundary Projects

**Definition**: Project affecting **≥2 sub-groups** (e.g., Aegis-Forge Alpha-12/13/14 spanning Pewenche headwaters → Wenteche river → Lafkenche estuary).

### 3.6.2 Wallmapu Wenuy Consent Protocol

```
PROTOCOLO DE CONSULTA INTER-SUB-GRUPOS — WALLMAPU WENUY

ARTÍCULO 1 — ACTIVACIÓN
1.1 SEA notifica a Wallmapu Wenuy cuando proyecto afecta ≥2 sub-grupos.
1.2 Secretaría Wallmapu Wenuy convoca sesión extraordinaria (15 días).

ARTÍCULO 2 — PROCESO PARALELO + SECUENCIAL
2.1 **Fase Paralela**: Cada sub-grupo ejecuta SU protocolo propio (Lafkenche marítimo, Wenteche cuenca, Pewenche Butalmapu, Nagche territorial).
2.2 **Fase Secuencial**: Resultados sub-grupos → Wallmapu Wenuy.
   - Si **TODOS consienten** → Wallmapu Wenuy ratifica (consenso 4 sub-grupos).
   - Si **ALGUNO veta** → **Veto general** — proyecto bloqueado.
   - Si **MEZCLA** (algunos consienten, otros sin consenso) → **Prórroga indefinida** — no procede mayoría.

ARTÍCULO 3 — DISTRIBUCIÓN DE BENEFICIOS TRANSFRONTERIZOS
3.1 FBC/CDC Trusts por sub-grupo reciben aportes **proporcionales a impacto territorial**.
3.2 Fórmula distribución:
   $$\text{Share}_i = \frac{\text{Impact Area}_i \times \text{Vulnerability Index}_i}{\sum_j \text{Impact Area}_j \times \text{Vulnerability Index}_j}$$
3.3 **Fondo de Solidaridad Inter-Sub-Grupos (10% total)** — redistribución a sub-grupo más vulnerable.

ARTÍCULO 4 — MONITOREO CONJUNTO
4.1 **Centinelas Inter-Sub-Grupos** — 2 por sub-grupo, acceso cruzado a territorios.
4.2 **Dashboard Unificado** — datos hidrológicos, calidad aire/agua, bosque, marino, cultural.
4.3 **Alerta Temprana** — cualquier centinela detecta umbral → notificación a 4 sub-grupos + Wallmapu Wenuy.

ARTÍCULO 5 — DISPUTA INTER-SUB-GRUPOS
5.1 Mecanismo: **Mediación Machi Cuádruple** (Machi Lafkenche + Machi Ko + 3 Machi Pewenche + Machi Mapu).
5.2 Decisión: **Consenso 7 Machi** — vinculante.
5.3 Apelación: **Tribunal Ambiental + Corte Suprema** — solo vicios de procedimiento.
```
