## 5.5 Bravo-6 — Coastal Electro-Kinetic REE (Lafkenche Territory)

### 5.5.1 Technology Specification — Zero Chemical Leaching

**Electro-Kinetic Extraction Cell Design**:
```
┌─────────────────────────────────────────────────────────────┐
│  ELECTRO-KINETIC REE EXTRACTION MODULE (EK-REM-100)         │
├─────────────────────────────────────────────────────────────┤
│  Feed: Ion-adsorption clay slurry (25% solids, pH 4.5)     │
│  Anode: Ti/IrO₂ (dimensionally stable) — 2 V/cm field      │
│  Cathode: Stainless steel 316L — REE³⁺ collection          │
│  Membrane: Cation exchange (Nafion®) — compartmentalized   │
│  Electrolyte: 0.1 M NH₄Cl (recycled, 95% recovery)         │
│  Residence Time: 48 hours (continuous flow)                │
│  Recovery: 68–75% TREO (HREE 70–78%)                       │
│  Energy: 18 kWh/kg REO (solar-powered)                     │
│  Footprint: 20m × 15m × 8m per 100 t/day module            │
└─────────────────────────────────────────────────────────────┘
```

**Process Chemistry**:
$$\text{Clay-REE}^{3+} + 3\text{NH}_4^+ \xrightarrow{E\text{-field}} \text{REE}^{3+}_{(aq)} + 3\text{NH}_4^+_{(ads)}$
$$\text{Cathode Reaction: } \text{REE}^{3+} + 3e^- \rightarrow \text{REE}^0 \text{ (dendritic deposit)}$
$$\text{Anode Reaction: } 2\text{H}_2\text{O} \rightarrow \text{O}_2 + 4\text{H}^+ + 4e^-$$
$$\text{Net: } \text{Clay-REE} + 3\text{H}_2\text{O} \xrightarrow{E} \text{REE}^0 + \frac{3}{2}\text{O}_2 + 3\text{H}^+_{(ads)}$$

**pH Control**: **Catholyte pH 2.5–3.0** (REE precipitation as hydroxide) → **acid recovery loop**
