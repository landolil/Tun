## 2.1 Tocopilla Port — Codelco's Cathode Gateway & SQM's Iodine Hub

### 2.1.1 Port Governance & Concession Structure

| Element | Specification |
|---------|---------------|
| **Port Authority** | **EMPORCHA** (Empresa Portuaria Antofagasta) — Law 19.542 |
| **Concession Model** | **Mixed**: EMPORCHA direct operation + Codelco/SQM dedicated facilities |
| **Codelco Facilities** | **Concession 2005–2035** (30 yr) — Dedicated cathode berth, warehouse, rail yard |
| **SQM Facilities** | **Concession 2010–2040** (30 yr) — Iodine berth, prilling plant, storage |
| **EMPORCHA Direct** | General cargo, breakbulk, cruise (occasional), port services |
| **Directorio Representation** | 3 President appointees, 2 GORE, 1 Worker (Sindicato Portuario), 1 User (Codelco/SQM) |

### 2.1.2 Cathode Terminal — Codelco's Dedicated Asset

| Parameter | Specification |
|-----------|---------------|
| **Berth** | **Sitio 1** — Dedicated, 250m length, -12m depth, Panamax (65k DWT) |
| **Shiploader** | **1 mobile harbor crane (100t)** + conveyor system (500 t/hr) |
| **Warehouse** | **50,000 m² covered** — Automated stacking (80k ton capacity), humidity control |
| **Rail Yard** | **12 tracks, 8 km total** — FCAB spur entry, 400 kt/yr capacity, 3 train simultaneous |
| **Cathode Handling** | **Bundle (1.5t) → Crane → Warehouse → Ship** — Zero intermediate handling |
| **Quality Control** | **In-line sampling (XRF)**, LME Grade A certification, digital CoA blockchain |
| **2023 Throughput** | **380 kt** (95% capacity) — Target 400 kt with Chuqui UG ramp-up |
| **Vessel Turnaround** | **36 hrs avg** (vs 48 hrs industry) — Dedicated berth, no queue |

**Cathode Logistics Chain**:
```
CALAMA (Chuqui UG/RT SX-EW/MH Concentrate) 
    → FCAB RAIL (180 km, 400 kt/yr capacity, 24/7 ops)
    → TOCOPILLA RAIL YARD (12 tracks, automated sorting)
    → CATHODE WAREHOUSE (50k m², climate controlled, RFID tracking)
    → SHIPLOADER (Mobile crane + conveyor, 500 t/hr)
    → VESSEL (Panamax, dedicated berth, priority scheduling)
    → DESTINATION: Asia (Qingdao 45d, Busan 38d, Tokyo 40d), Europe (Rotterdam 35d), USA (Houston 32d)
```

### 2.1.3 Iodine Terminal — SQM's Global Hub

| Parameter | Specification |
|-----------|---------------|
| **Berth** | **Sitio 2** — Shared general, 200m, -14m depth, Handymax (45k DWT) |
| **Prilling Plant** | **On-site (SQM)** — 20 kt/yr capacity, iodine prills (2-4mm), bagging |
| **Storage** | **15,000 m² covered** — Big bags (1t), containers (20t), climate controlled |
| **Rail Access** | **FCAB Spur** — Iodine train from Pampa del Tamarugal (120 km) |
| **Throughput** | **18 kt/yr** — 60% world supply, 99.9% purity (pharma grade) |
| **Value Density** | **US$35/kg** — Highest $/ton in port, security priority |
| **Export Split** | **Containerized (80%)** — Reefer 15°C, security seals, GPS tracking |
| **Key Markets** | USA (pharma, X-ray), EU (catalysis, LCD), Japan (polarizers), China (polarizers, pharma) |

### 2.1.4 FCAB Tocopilla Spur — The Critical Rail Link

| Specification | Detail |
|---------------|--------|
| **Length** | **180 km** (Calama → Tocopilla) |
| **Gauge** | 1,000 mm (meter gauge) — **Only meter gauge in Chile** |
| **Traction** | **Diesel-electric (GT26/GT22)** — 12 locos dedicated, electrification study 2025 |
| **Capacity** | **400 kt/yr cathode + 20 kt/yr iodine** — Current utilization 95% |
| **Journey Time** | **4.5 hrs** (cathode), 3.5 hrs (iodine) — Single track, passing loops |
| **Grade** | **2.5% max** (Cuesta Tocopilla) — Rack-assisted historically, now adhesion |
| **Modernization Plan (2025–2028)** | **Electrification (25 kV AC)**, passing loop doubling, CTC signaling, 600 kt/yr capacity |
| **Investment** | **US$320M** (Codelco 60%, FCAB 20%, GORE 20%) |
| **Strategic Value** | **Only rail link** for Calama cathode — No road alternative (Route 1 too steep for 400 kt/yr) |
