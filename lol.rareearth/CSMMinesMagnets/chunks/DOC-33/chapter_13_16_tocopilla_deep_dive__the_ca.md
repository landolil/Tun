## 1.6 Tocopilla Deep Dive — The Cathode & Iodine Port

### 1.6.1 Tocopilla Port — Codelco's Cathode Gateway

| Parameter | Specification |
|-----------|---------------|
| **Operator** | **EMPORCHA** (direct) + **Codelco** (dedicated facilities) |
| **Berths** | 3 berths: 1 dedicated cathode (Codelco), 2 general/iodine |
| **Depth** | -12m (cathode), -14m (general) |
| **Cathode Throughput** | **380 kt/yr** (Chuqui/RT/MH cathode via FCAB rail) |
| **Iodine Throughput** | **18 kt/yr** (SQM, ~60% world production) |
| **Storage** | 50,000 m² cathode warehouse (Codelco), 15,000 m² iodine (SQM) |
| **Rail Access** | **FCAB Spur** (Tocopilla branch, 180 km from Calama) — 400 kt/yr capacity |
| **Vessel Size** | Panamax (65,000 DWT) cathode, Handymax (45,000 DWT) iodine |

### 1.6.2 Iodine Industry — SQM's Global Dominance

| Metric | Value | Global Context |
|--------|-------|----------------|
| **Production** | **18 kt/yr** (SQM Tocopilla) | **~60% world supply** |
| **Reserves** | Caliche ore (Pampa del Tamarugal) | **Largest known deposits** |
| **Process** | Caliche leaching → iodide → oxidation → prilling | **Unique to Chile** |
| **Export Markets** | USA (35%), Europe (25%), Japan (20%), China (15%), Others (5%) | **Pharmaceutical, X-ray, LCD, catalysis** |
| **Revenue (SQM Iodine)** | ~US$600M/yr | **High-margin, price inelastic** |
