## 8.4 Key Regulatory Interfaces — Detailed

### 8.4.1 INACH — Antarctic Science & Logistics Partner

| Function | Kawéskar/Yagán Interface | Trust Mechanism |
|----------|--------------------------|-----------------|
| **Science Permits** | **Yagán/Kawéskar co-design** required for projects in WCS/CHBR/Beagle | **YHT/MTT review + Yekamush/Kalku consent** |
| **Logistics Contracts** | **30% minimum to Indigenous operators** (AGF, MTT, YHT) | **AGF manages** — transparent procurement |
| **Environmental Protocol** | **Madrid Protocol Annex I EIA** — Kawéskar/Yagán as **affected communities** | **Sentinels monitor compliance** |
| **Cape Horn Biosphere** | **INACH + CONAF + Yagán CCY** co-management | **Yagán veto on Core zone** |
| **Data Sharing** | **Open science** — **TK co-owned, Yagán/Kawéskar control access** | **YHT/MTT data sovereignty license** |

### 8.4.2 DIRECTEMAR — Maritime Authority & Sovereignty

| Function | Kawéskar WCS | Yagán Beagle/Cape Horn |
|----------|--------------|------------------------|
| **Maritime Concessions** | **CECMK veto** on new concessions in WCS | **CCY veto** in Yagán territory |
| **Port Development** | **Punta Arenas/Puerto Natales** — Kawéskar consent | **Puerto Williams** — Yagán consent |
| **Navigation Safety** | **Kalku certification** for traditional routes | **Yekamush certification** for awa routes |
| **Polar Code Enforcement** | **Kawéskar Sentinels = inspectors** (Decree 120 Art 9) | **Yagán Sentinels = inspectors** (CHMPA) |
| **SAR Coordination** | **MRCC Punta Arenas** — Kawéskar crew on SAR vessels | **MRCC Puerto Williams** — Yagán crew |
| **Antarctic Treaty Inspections** | **Observer status sought** — Kawéskar/Yagán on inspection teams | **CCAMLR/ATS** — Indigenous observers |

### 8.4.3 CCAMLR — Marine Living Resources

| Issue | Kawéskar/Yagán Position | Mechanism |
|-------|------------------------|-----------|
| **Toothfish (Dissostichus)** | **Precautionary catch limits** — ecosystem approach | **MTT/YHT scientific observers** on all vessels |
| **Krill (Euphausia superba)** | **No fishing in WCS/CHBR** — forage base for whales/penguins | **CCAMLR Conservation Measure** — Yagán/Kawéskar propose |
| **MPAs (Domain 1, 8, 9)** | **Support** — **co-proponents with Chile/Argentina** | **Yagán/Kawéskar as MPA co-managers** |
| **Climate Change** | **Ecosystem-based management** — sentinel data to CCAMLR | **MTT/YHT sentinels = official data providers** |
