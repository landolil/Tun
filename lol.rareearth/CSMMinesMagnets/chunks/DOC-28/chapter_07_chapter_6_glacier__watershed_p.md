## Chapter 6: Glacier & Watershed Protocol

### 6.1 Glacier Law 21.435 — Pehuenche Implementation

**Law 21.435 (2022) Key Provisions for Pehuenche**:

| Article | Provision | Pehuenche Application |
|---------|-----------|----------------------|
| **Art 1** | Glaciers = public goods, strategic reserves | Pehuenche = **guardians** (Art 10) |
| **Art 4** | Glacier inventory (DGA) | **DGA 2023: 122 glaciers in Pehuenche headwaters** |
| **Art 5** | Human consumption > ecosystems > productive | **Pehuenche ceremonial water = ecosystem priority** |
| **Art 7** | Prohibited: glacier removal, coverage, pollution | **Alpha clusters: 1km buffer = zero disturbance** |
| **Art 10** | Indigenous peoples in glacier areas = special protection | **Pehuenche consent required for ANY glacier-adjacent activity** |
| **Art 12** | Glacier monitoring mandatory | **GPF funds Pehuenche-led monitoring network** |

**Pehuenche Glacier Protocol — Operational**:

1. **Annual Glacier Health Assessment** — **Pehuenche glaciologists (PTI grads) + DGA + university**
2. **Dust Deposition Monitoring** — **monthly sampling at 20 stake stations** — **threshold: >0.5 g/m²/day = Alpha operations pause**
3. **Mass Balance Tracking** — **stake network + GPR + satellite (Copernicus Sentinel-2)** — **target: mass balance ≥ 0 by Year 10**
4. **Community Sentinel Authority** — **Pehuenche sentinels can halt Alpha operations** if glacier impact threshold exceeded
5. **Restoration Bond** — **Alpha clusters post US$50M bond per cluster** — **forfeit if glacier mass balance negative at Year 10**

3. **Agriculture/livestock** (Pehuenche subsistence)
4. **Aegis-Forge** (only from WSF desalination, zero headwater withdrawal)
5. **Legacy mining** (phased reduction as desal comes online)
