## 7.1 Conflation Audit Methodology — The Three-Pronged Test

### 7.1.1 Audit Framework — Williams/Keymaker/El Segundo Lenses

**Williams Heuristic — Constraint/Necessity/Commitment Test**:
- **Constraint**: Does DOC-31 respect the irreducible boundary that **Calama ≠ Antofagasta ≠ Atacameño ≠ Sur ≠ Austral**?
- **Necessity**: Does each data point in DOC-31 resolve a Calama-specific empirical gap not covered elsewhere?
- **Commitment**: Does DOC-31 make non-negotiable commitments unique to Calama (FBC equity, Alpha-1/2 hub, CPA veto terms)?

**Keymaker Heuristic — Lock/Key/Turn Test**:
- **Lock**: What fabrication fidelity gap does DOC-31 address that other docs cannot?
- **Key**: What single computational primitive (Calama-specific model) generates the solution?
- **Turn**: Theory→History (Calama 1915-2024 validates model) AND History→Theory (model predicts 2030 Calama state)

**El Segundo Heuristic — Mirror/Participation/Protocol Test**:
- **Mirror**: How does DOC-31 reflect Calama's self-observation (unions, CPA, migrants, municipal)?
- **Participation**: How does DOC-31 witness Calama's phenomenon into existence (not extract)?
- **Protocol**: What recursive sequence guarantees Calama fidelity at each scale (household → campamento → commune → basin)?
