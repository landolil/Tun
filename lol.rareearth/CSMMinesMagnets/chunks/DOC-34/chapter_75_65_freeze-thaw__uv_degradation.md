| **Asphalt (Roads)** | 120 | 2,800 | Binder oxidation + ice wedging → potholes | 8-10 yr | **15-20 yr (PMB + fiber + drainage)** |

### 6.5.2 Heritage-Specific: Adobe Preservation Protocol

```
ADOBE PRESERVATION — FREEZE-THAW + UV PROTOCOL

ANNUAL CYCLE (Pre-winter, April):
1. INSPECTION: CPA + DIBAM + Univ. Católica → Crack mapping (photogrammetry)
2. CLEANING: Soft brush, no water (soluble salts)
3. SACRIFICIAL PLASTER: 15mm mud-straw-lime (traditional mix + 5% cactus mucilage)
4. BREATHABLE SEALER: Silane-siloxane (penetrating, vapor permeable, UV resistant)
5. DRAINAGE CHECK: Roof runoff, foundation grading, capillary break

POST-EVENT (Flood/Seismic):
1. RAPID ASSESSMENT (24hr): CPA monitor + DIBAM → Structural stability
2. EMERGENCY SHORING: Timber/steel props, mudbag buttresses
3. SALT EXTRACTION: Poultice (clay-cellulose) if flood wetted walls
4. DOCUMENTATION: 3D laser scan → Digital twin update

MONITORING (Continuous):
├── Crack gauges (50 key structures) — Monthly reading
├── Embedded moisture sensors (10 structures) — 15-min data
├── Thermal cameras (drone, quarterly) — Delamination detection
└── Kimün reading (elders, quarterly) — The walls speak
```
