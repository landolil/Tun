## 7.4 Power Generation — Binary ORC for Calama Grid

### 7.4.1 Technical Specification — El Tatio 20 MWe Plant

| Component | Specification |
|-----------|---------------|
| **Technology** | Binary ORC (Organic Rankine Cycle), isopentane working fluid |
| **Wellfield** | 8 production wells (25 kg/s each), 4 reinjection wells |
| **Well Depth** | 1,800-2,200m (directional, clustered pad) |
| **Wellhead Pressure** | 15-20 bar |
| **Separator** | 2-phase (steam + brine) at 10 bar |
| **Turbine** | 2 × 10 MWe radial outflow, 3,000 rpm |
| **Condenser** | Air-cooled (water-scarce), 45°C condensing |
| **Reinjection** | 95% fluid return, 4 wells, monitored |
| **Capacity Factor** | **92%** (geothermal baseload) |
| **Annual Generation** | **161 GWh/yr** |
| **Grid Connection** | 220 kV line (45 km to Calama SE) — shared with solar |
