## 3.6 Quality Monitoring — The Tripartite Protocol

### 3.6.1 Monitoring Network Design

| Parameter | Frequency | Locations | Responsible | Standard |
|-----------|-----------|-----------|-------------|----------|
| **Arsenic, Boron, Fluoride** | Monthly | 7 wells + 5 taps + 3 distribution | **SEREMI Salud (lead) + CPA lab + DGA** | WHO / NCh 409 |
| **Microbiological (E. coli, Total Coliform)** | Weekly | 10 taps + 2 reservoirs | SEREMI Salud | NCh 409 |
| **Physicochemical (pH, EC, TDS, Hardness)** | Continuous (sensors) | 3 wellheads + 2 tanks | Municipal APR | DGA norms |
| **Isotopes (δ¹⁸O, δ²H, ³H, ¹⁴C)** | Quarterly | 4 wells | **CPA + Univ. Católica (kimün + science)** | IAEA protocols |
| **Water Level (Piezometers)** | Continuous (15-min) | 8 monitoring wells | **DGA + CPA** | DGA Red Nacional |

### 3.6.2 Data Governance — The CPA Co-Ownership Model

```
WATER DATA GOVERNANCE FRAMEWORK — PURIPURA-CHIU CHIU

DATA OWNERSHIP:
├── Raw sensor data: **Joint ownership (Municipal + CPA + DGA)**
├── Processed analytics: **CPA leads interpretation (kimün integration)**
├── Public reporting: **Monthly dashboard (tripartite approval)**
└── Regulatory submissions: **DGA (legal), SEREMI Salud (health)**

ACCESS RIGHTS:
├── Communities (Ayllus): **Full real-time access via CPA portal**
├── Tourism Operators: **Aggregated weekly (no well-level data)**
├── Mining Companies: **Zero access (CPA veto)**
├── Researchers: **Open access (anonymized, 1-yr embargo)**
└── Government: **Full access (transparency law)**

DECISION TRIGGERS:
├── As > 0.012 mg/L at any tap → **Immediate CPA + SEREMI alert → Tanker supply**
├── Drawdown > 5m/yr sustained → **Automatic extraction reduction (DGA order)**
├── ³H detection in any well → **Modern recharge confirmed → Recalibrate model**
└── Community health cluster → **Epidemiological investigation (SEREMI + CPA)**
```
